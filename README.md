# Give Dance Presentation

**V1.0** — A bilingual HTML presentation for the Give Dance product design project with Deaf K-pop dancers.

## View

Open the deployed presentation:

https://givedance.github.io/Give-Dance-Presentation/

## Controls

- `←` / `→`: Navigate slides
- `F`: Enter or exit fullscreen
- `中 / EN`: Switch between Chinese and English
- Videos: Click the native play control to start

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.
