# Give Dance Presentation

**V1.2** — A bilingual HTML presentation for the Give Dance product design project with Deaf K-pop dancers.

## Controls

- `←` / `→`: Navigate slides
- `⌂`: Return to the first slide
- `F`: Enter or exit fullscreen
- `中 / EN`: Switch between Chinese and English
- Videos: Click the native play control to start

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.
